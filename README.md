# 🎬 Screenmatch

Aplicação desenvolvida em **Java** durante meus estudos de programação, com o objetivo de praticar **Programação Orientada a Objetos**, consumo de APIs e manipulação de dados em JSON.

O projeto utiliza a **OMDb API** para buscar informações sobre filmes e séries.

## 📌 Sobre o projeto

O Screenmatch permite realizar buscas por filmes e séries através da API do OMDb e trabalhar com os dados retornados pela API dentro da aplicação.

O projeto foi desenvolvido durante meus estudos na **Alura** como forma de colocar em prática conceitos fundamentais da linguagem Java.

## 🚀 Funcionalidades

* 🔎 Busca de filmes e séries
* 🎬 Consulta de informações através da OMDb API
* 📡 Consumo de API externa
* 📄 Conversão e manipulação de dados JSON
* 🧩 Organização dos dados utilizando classes Java
* ⚠️ Tratamento de possíveis erros durante as consultas

## 🔌 OMDb API

O projeto utiliza a **OMDb API (The Open Movie Database)** para obter informações sobre filmes e séries.

As consultas são realizadas a partir do título informado pelo usuário, e os dados retornados são processados pela aplicação.

## ▶️ Como executar

### Pré-requisitos

* Java instalado
* IntelliJ IDEA ou outra IDE compatível
* Uma chave de acesso da OMDb API

### Executando o projeto

1. Clone este repositório:

```bash
git clone https://github.com/onxfreak/Screenmatch.git
```

2. Abra o projeto na sua IDE.

3. Configure sua chave da **OMDb API** de acordo com a estrutura utilizada no projeto.

4. Execute a aplicação.

5. Informe o nome de um filme ou série para realizar uma consulta.
